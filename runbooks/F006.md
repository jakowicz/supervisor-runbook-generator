## Objective

Create `projects/<project-slug>/planning/06-foundation-domain-contracts.md`.
Turn the foundation work from F005 into atomic implementation-contract records:
bootstrap, configuration, architecture seams, design tokens, data model,
persistence, identity, authorization, and test harnesses. This is an authoring
input, not an attempt to write every final implementation runbook in one task.

## Acceptance criteria

- Each record has a stable implementation ID, bounded outcome, dependencies,
  file/data ownership, verification, and acceptance evidence.
- Contracts identify shared and target-specific work without implementing later
  features early or substituting placeholders.
- The document is sufficient for a later batch author to create valid Supervisor
  runbooks without reinterpreting the brief.
