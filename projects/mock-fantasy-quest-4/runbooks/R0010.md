## Objective

Define original semantic tokens for typography, spacing, focus, motion, touch
targets, status, contrast, and non-colour cues. The contract enables later
responsive web UI and inherited PWA UI without selecting final visual assets or
numeric design decisions that remain gated.

## Dependencies

R0001 and R0002 are implementation dependencies. Retain GATE-0002 and
GATE-0004 for numeric contrast, font, and breakpoint claims; neither gate
blocks authoring this bounded token contract.

## Ownership

- `src/app/design/tokens/` and the semantic token inventory.
- `docs/design-tokens.md` and `tests/app/design-tokens.*`.
- The token consumption contract used by shared UI, web, and PWA adapters.

## Behaviour

Use semantic names such as surface, text, action, status, focus, spacing,
typography, motion, and target-size rather than screen- or asset-specific
values. Require visible focus, text-plus-shape/icon status cues, and
reduced-motion values that remove nonessential motion. Support scalable text,
semantic labels, and non-colour state indication without binding tokens to a
specific component or final visual composition.

## Web and PWA differences

Web UI consumes the shared semantic contract across responsive layouts. The
installed PWA inherits those tokens and accessibility behaviour; installation,
cache, and display-mode adaptation do not introduce a separate token system.
No final breakpoint or browser/device compatibility claim is made.

## Non-goals

Do not build screens, maps, layouts, final breakpoints, final artwork, fonts,
icons, audio, animations, or copied reference styling. Do not approve numeric
contrast, font, or breakpoint values while GATE-0002 and GATE-0004 remain
unresolved.

## Asset assessment

`asset_impact` is `not_applicable`. This semantic contract explicitly
prohibits incidental asset creation: no final art, fonts, icons, audio, maps,
or other product assets may be created or reserved.

## Verification

- Validate representative token fixtures contain semantic labels and
  text/non-colour cues for status.
- Validate reduced-motion values remove nonessential transitions without
  suppressing essential information.
- Confirm focus, target-size, typography, spacing, and status tokens are
  semantic and do not encode a screen or final asset.
- Record GATE-0002 and GATE-0004 as retained before any numeric design,
  contrast, font, or breakpoint claim.

## Evidence

Preserve token-validation results, representative non-colour and
reduced-motion fixtures, and the explicit retained-gate record.

## Acceptance criteria

- Semantic tokens provide non-colour cues and reduced-motion values.
- The token contract can be consumed by web and PWA UI without platform forks.
- No final visual assets or approval-gated numeric claims are introduced.
